5. Cần bạn chốt

(a) Đã có file ký thì cột trái mở mặc định tab nào? — đề xuất File đã ký.
(b) Khung xem PDF nhúng cần 1 route nhỏ mới GET /api/maintenance/records/[id]/file-url (kiểm đăng nhập + đúng nhà máy, trả đường dẫn file ký hiện tại) — giống Văn bản/ISO. Đồng ý thêm?
(c) "Hủy biên bản" / "Hủy phê duyệt" / "Đảo xuất kho" / "Xóa" giữ đúng điều kiện cũ, gom vào nhóm nút đỏ; "Ký ngay" hoặc "Gửi ký duyệt" là nút chính duy nhất.
